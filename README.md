# Oro House

Marketing site for the Oro House café — Next.js (App Router, JavaScript), React and Framer Motion.
No photography: the facade, staircase, espresso glass and the gingham cloth are all drawn in SVG and canvas.

## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Structure

- `app/layout.js` — fonts (Bodoni Moda / Jost / Yellowtail), preloader, smooth scroll, nav, footer
- `app/globals.css` — design tokens (cream, oro red, burgundy, gold) and shared primitives
- `components/`
  - `Preloader` — gingham tiles pop in, wordmark lands, curtain lifts
  - `SmoothScroll` — Lenis, with anchor links routed through it
  - `GinghamCanvas` — the woven cloth behind the hero; threads breathe and lift under the pointer
  - `Hero`, `Cup` — scroll-parallax wordmark over the gingham cloth, with a steaming
    espresso glass
  - `Marquee` — ribbon whose speed and direction follow scroll velocity
  - `House`, `Brewhead` — the group head pulls a shot as you scroll: pressure gauge,
    converging tails, the glass filling, live time/bar/grams readout
  - `MenuRail` — pinned section that scrolls the five menu panels sideways
  - `LongTable` — checkerboard laid square by square
  - `Visit` — hours (today highlighted), copy-to-clipboard details, reservation form
  - `Magnetic`, `Reveal`, `SplitWords`, `Counter` — motion primitives

Every animation collapses under `prefers-reduced-motion`.

## Placeholders to replace

House details (name, address, phone, email, url, socials) all live in **`components/site.js`** —
change them there and the page, the footer, the directions link and the search-engine
structured data all follow. Opening hours live in `components/hours.js`, shared by `Visit`
and the JSON-LD. Still placeholders: the address, phone, email, url, and the stats
(9 m / 18 / 92) in `components/House.js`.

### Bookings

The reservation form posts JSON to `NEXT_PUBLIC_BOOKING_ENDPOINT` when that env var is set
(a form service, a webhook, your own route handler). With no endpoint configured it hands the
request to the guest's mail client instead, addressed to `SITE.email`. It deliberately never
shows a confirmation for a request that went nowhere.

Bookable times are generated by `slotsFor()` in `components/hours.js` from the real opening
hours for the chosen day — every 30 minutes from opening until an hour before close, with
anything inside the next 45 minutes dropped when the date is today. There is no hardcoded
list of times to fall out of sync. The house rules are enforced rather than just advertised:
the first floor is selectable only from 19:00, the date is clamped to today..+90 days, and
parties of seven or more are pointed at the phone.
The menu in `components/MenuRail.js` is the real one — five counters (burgers, mains, pasta,
pizzas, desserts) transcribed from the printed card.

Photographs live in `public/brew/`; see the README there for how they were produced.
`01.jpg` is no longer on the page — it is still the social share image (`app/layout.js`).

`_archive/` holds the earlier single-file static version, and `_archive/svg/` the retired
`Facade`/`Staircase` illustrations and the retired `FlipBoard`, `LatteArt`, `Brew` and `Clock`
sections. `components/hours.js` stays — `Visit` reads the opening hours from it.
